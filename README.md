## 구조
- `index.html` — 메인. 영역 카드를 보여줌
- `macro/` 거시경제, `korea/` 한국경제, `realestate/` 대한민국 부동산, `stocks/` 주식 — 영역 페이지
- `영역/작품이름/index.html` — 작품 하나 → `https://choco1161.github.io/first/macro/작품이름/`
- `assets/site.js` — 영역 목록(`AREAS`)과 작품 목록(`PROJECTS`). 새 작품은 `PROJECTS`에 한 줄 추가
- `assets/style.css` — 공통 디자인
